# GIF smoothness vs size (review page)

The 720p GIFs on the changes page were **1–1.7 frames per second** (keyframes only), to fit a 5 MB budget. That's why they looked choppy. Here is the same 6-second Tech hint clip at full motion:

| Keyframe GIF (what you saw) | 1.7 fps | 4.7 MB |
| **Smooth GIF**, 256 colours | 12 fps | 13.2 MB |
| Smooth GIF, 128 colours | 12 fps | 10.8 MB |
