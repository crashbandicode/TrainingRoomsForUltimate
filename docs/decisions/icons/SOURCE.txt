How the mockups use them: the renderer parses each path and fills it with Pillow at 8x size, then downsamples.
The colour, the dot under the loop, and the count drawn inside the loop are added by the renderer.
Revision 7 dropped pins, so the push_pin icon that revision 4 used was removed from this folder.
