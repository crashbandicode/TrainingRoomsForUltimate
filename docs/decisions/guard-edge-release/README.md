# Guard the Edge: what differs between rounds at one start

Eden, 2026-11-26, merge 17 (`5df3d9dc`), Kirby against a CPU Mario on the Training stage. Not run on hardware.

- `release-round1-airdodge-vs-round2-fall.mp4` is **drawn from measured positions, not game footage**: the CPU's world position on each frame after release, round 1 beside round 2, at quarter speed. Its caption names the frame and the CPU's own input.
- `ready-in-view-rounds-2-3-4.mp4` and `.png` are **game stills**: three rounds in a row at Ready, start (−100, −20). The CPU is at the same world point; the camera frames it differently.
- `ready-default-start-rounds-2-3-4.mp4` and `.png` are **game stills** too: the default start (−125, −68), where the CPU is out of view and shown in the game's magnifier.
