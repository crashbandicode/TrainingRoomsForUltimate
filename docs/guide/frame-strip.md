## Read an exchange

*Two jabs leave two A presses on the frame strip.* [Open the clip](../media/tut-input-display-whole.mp4)

| Look at | What it tells you |
|---|---|
| Fighter lanes | Time moves right; one column is one game frame. |
| Gold → red → blue | Player 1's startup, active hitbox, then recovery or other busy frames. |
| Light grey / purple / teal | Hitlag, hitstun and shieldstun respectively. |
| Dark blue-grey | The fighter can act, including a cancel window. |
| Chip and arrow | A new button press and its direction; the stick lane shows held direction. |
| <a id='advantage'></a>ADVANTAGE | Positive: you can act first. Negative: the CPU can act first. |
| <a id='link'></a>LINK | TRUE: follow-up landed before escape. DROP: the positive number is frames late. |
| <a id='input'></a>INPUT | Zero is on time; negative is buffered; positive is late. |
| LAST | Your most recent follow-ups, newest first. |
| <a id='scroll-back'></a>Scroll back | Hold R3, press Left/Right on the D-pad, then release R3 for live frames. |
| Strip not moving? | It freezes during idle stretches to keep the exchange visible. |
| <a id='turning-it-on-and-off'></a><a id='spot-labels'></a>Change what's shown | See [Input Display](../menu/display-and-controls.md#input-display) and [Spot labels](../menu/display-and-controls.md#spot-labels). |
