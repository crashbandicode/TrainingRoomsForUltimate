## Tech a surface on impact

*The third attempt is a missed tech.* [Open the clip](../media/tut-tech-practice.mp4)

| Step | What to do |
|---|---|
| 1. Choose a session | Open Tech practice in [Practice games](../menu/practice-games.md), then choose **Tech wizard**. |
| 2. Aim | Place Spot on a surface. Adjust Angle, Distance and Hit. A advances each step. |
| 3. Preview | Check the dotted path. If blocked, press B back to Distance or Angle and adjust. |
| 4. Launch | A or Plus starts from Preview; **Skip wizard preview** starts immediately after Hit. |
| 5. Tech | Press shield just before touching the surface; compare the grade and streak. |
| Factory settings | A miss counts as an attempt; the next launch follows until the set ends. |
| No launch fits these Tech practice values | No launch with these values reaches a surface; change them or restore defaults, then restart. |
| Start position Set or Random | The launch is checked first; Random draws only values that reach a surface, sometimes slowly. |
| Pick just the impact point | Use **Tech point** instead of the wizard; X starts from a valid point. |
