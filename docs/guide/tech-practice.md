Works in Training and in the [waiting room](waiting-rooms.md). In [Practice games](../menu/practice-games.md#tech-practice), choose a session and **Tech wizard**, or choose **Surface** and **Start**. Press shield just before the launch reaches the surface; the notice shows your timing grade when available, your streak and session results.

The wizard takes you through **Spot**, **Angle**, **Distance**, **Hit** and **Preview**. Move the cursor to a surface, adjust the angle and distance, then choose and adjust launch speed and hit damage. The dotted path is approximate; adjust the setup if the preview says the start is blocked. The input display strip is hidden while the wizard is open.

**Tech point** opens a crosshair to select a surface without the wizard. The other settings let you choose damage, launch, DI, facing, delay and camera; Auto aim is approximate, especially on walls and undersides.

| Button | What it does |
| --- | --- |
| Stick or D-pad | Move the crosshair; adjust wizard values. |
| A | Choose a point or go to the next wizard step; start from Preview. |
| B | Go back, or cancel from the first wizard step. |
| X | Use defaults and go to Preview in the wizard; start from Tech point. |
| + | Start from a valid wizard setup. |
| Shield | Tech just before touching the surface. |
