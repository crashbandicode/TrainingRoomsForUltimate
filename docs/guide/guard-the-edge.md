# Guard the Edge

## Stop the recovery and get back

<video src="https://git.syntaxbyexample.com/intpa/TrainingRoomsForUltimate/media/blob/fdc7a4382ed255e1ebda8d4dc1dd87f43ca16e9c" autoplay muted loop playsinline controls></video>

*Place the CPU offstage, then secure a stock.* [Open the clip](../media/tut-guard-edge-setup-and-score.mp4)

| Step | What to do |
|---|---|
| 1. Choose your ledge | Stand on the floor to defend. Open [Practice games](../menu/practice-games.md) → **Guard the Edge**. |
| 2. Place the fighters | **Set up…** opens CPU start, Player 1 start, then Preview. [Still](../media/tut-gte-setup-help.png) |
| 3. Pick the CPU spot | Move offstage with the stick or D-pad. A accepts. Y tries the other side. |
| 4. Pick your spot | Aim above the main floor, press A, then A or Plus on Preview. |
| 5. Secure a stock | KO the CPU and get back to ground or ledge before the return window closes. |
| If you don't return | Your KO or an expired window earns no secured stock. |
| If setup opens again | Another floor, or disabling under-stage starts for a saved under-stage spot, requires new placement. |
| Adjust reaction | Choose Perfect mode first; stock CPU does not use Reaction. |
| Against Hero's Zoom | Time the hit or grab using the [Zoom landing window](../menu/practice-games.md#zoom-landing-window). |
