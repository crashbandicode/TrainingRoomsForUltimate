# Break the Targets

*Practice games › Break the Targets, with one target placed beside Mario: a jab, a forward tilt, then a short-hop back air breaks the target and it is gone. Eden, the diagnostic file of preview build `cc71537c`, 2026-11-27.* [Open the clip](../media/tut-break-the-targets.mp4)

Works in Training and in the [waiting room](waiting-rooms.md). Place up to ten targets, then break them as fast as you can. Choose **Start** in [Practice games](../menu/practice-games.md#break-the-targets): if this stage has no targets, the placement view opens first. The clock starts on your first gameplay input and stops when the last target breaks.

Use **Saved layouts** to load, rename, duplicate or delete a layout for the current stage. Editing a loaded layout does not overwrite it: save a new one to keep your changes. **Projectiles break targets** and **Hit streak** are optional.

| Button | What it does |
| --- | --- |
| Stick or D-pad | Move the placement crosshair. |
| A | Place a target. |
| B | Remove the last target. |
| Y twice | Clear all targets. |
| X | Start with at least one target. |
| ZL + Down | Save the current layout while placing. |
| ZL + Left/Right | Choose a recent layout while placing. |
| ZL + Up | Load the chosen layout while placing. |
| ZL + Y twice | Delete the chosen layout while placing. |
| L + R + A | Restart in Training when **L+R+A Reset** is On. |
