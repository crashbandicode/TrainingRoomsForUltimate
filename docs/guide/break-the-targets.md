# Break the Targets

## Place targets and race the clock

<video src="https://git.syntaxbyexample.com/intpa/TrainingRoomsForUltimate/media/blob/d8dc78d3f34bd83e7c687ed7ce791010bd1556e8" autoplay muted loop playsinline controls></video>

*Mario turns toward the target and punches it.* [Open the clip](../media/tut-break-the-targets.mp4)

| Step | What to do |
|---|---|
| 1. Open placement | Open [Practice games](../menu/practice-games.md) → **Break the Targets** → **Place targets**. Start opens placement without targets. |
| 2. Lay out the course | Move the crosshair with the stick or D-pad; A places a target, up to ten. |
| 3. Undo | B removes the last target; press Y twice to clear all. |
| 4. Race | Press X; your first gameplay input starts the clock, the last break stops it. |
| Keep this course | Use the Save chord while placing; edited layouts save as new layouts. |
| Recall a course | ZL + Left/Right selects a recent layout; the Load chord loads it. |
| Remove a layout | While placing, press ZL + Y twice on the selected layout. |
