# Juggler

Works in Training and in the [waiting room](waiting-rooms.md). Keep the CPU airborne as long as you can. In [Practice games](../menu/practice-games.md#juggler), choose **CPU fighter and mode**, **Reaction**, **Attempts** and **Start**.

On the first start, or with **Set up…**, pick the CPU's spot and percent, then Player 1's start above a floor or platform and preview both points. An invalid Player 1 point immediately says “Pick a point above a floor”. The input display strip is hidden while setup is open. Later starts remember the setup for the current stage; **Set up…** changes it.

The clock starts when the CPU is released. An attempt ends when it lands, catches the ledge or is KO'd; the notice shows the time, hits and best. Against Hero's **Zoom**, hit or grab him on the way down or within **Zoom landing window** after landing to win.

| Button | What it does |
| --- | --- |
| A | Open a fighter, cycle its mode, advance setup or start from Preview. |
| X | Change CPU level in its popup, or restore the default setup and preview it. |
| Stick or D-pad | Move the crosshair; on Percent, D-pad changes the value by 1 horizontally or 10 vertically. |
| B | Go back in setup, or cancel on the first page. |
| + | Start from Preview. |
| L + R + A | Restart the set when **L+R+A Reset** is On. |
