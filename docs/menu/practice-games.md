# Practice games

On Fighters & Stages, A on a game opens its screen: Start first, then the settings below.

## Eggs-ercise

<video src="https://git.syntaxbyexample.com/intpa/TrainingRoomsForUltimate/media/blob/d146fc36a0ab8dacc74690ea1c4e9dd700ddb96d" autoplay muted loop playsinline controls></video>
*A opens Eggs-ercise; Start begins it, Stop ends it.* [Open the clip](../media/tut-practice-start-stop.mp4)

Break the targets that appear ([guide](../guide/eggs-ercise.md)).

| Setting | Values (default in bold) | What it does |
| --- | --- | --- |
| Start, Stop | | Starts the game and closes the menu. Stop ends it. |
| Eggs-ercise | **1 minute**, 10 targets, 20 targets, Free practice | The goal or the time limit. |
| Breaks on | **Any attack**, Aerials, Hits of 12%+ | Which of your hits break a target, projectiles included. |
| Target | **Disc**, CPU | CPU flies like a disc. With [Hide CPU](cpu.md#hide-cpu) on, a disc replaces it. |
| Target speed | **Normal**, Slow, Fast | Slow is half speed. Fast is one and a half times as fast. |
| Spawn area | **In view**, Whole stage, Off stage | Each checked area has the same chance. |
| Off-stage zone… | Opens the zone editor | The edges of this stage's off-stage area. |
| Moving paths | Axe, Galaxian, Boomerang, Homing Missile, **Pop up** | Each checked flight path has the same chance. |
| Target expiry | **Off**, 1 to 10 seconds | Replaces an unhit target after that time. |
| Hit streak | **Off**, On | Shows your streak and session best. A whiff resets it. |
| CPU during a game | **Hide**, Show | Hides the opponent during Eggs-ercise unless it is the target. |

## Tech practice

<video src="https://git.syntaxbyexample.com/intpa/TrainingRoomsForUltimate/media/blob/31d110ca42ab2ca51e85e01734275117539643bb" autoplay muted loop playsinline controls></video>

*The counter reads 3/20 after a missed tech.* [Open the clip](../media/tut-tech-practice.mp4)

Tech a launch at a chosen or random surface; Set uses the low end of a range ([guide](../guide/tech-practice.md)).

| Setting | Values (default in bold) | What it does |
| --- | --- | --- |
| Start, Stop | | Start launches practice. Tech wizard and Tech point open separate setup views. |
| Tech practice | **20 attempts**, 10 attempts, 1 minute, 3 minutes, Free practice | How long a session lasts. |
| Tech wizard | Opens the wizard | Choose a spot, angle, start distance and hit. |
| Surface | **Any**, Floor, Wall, Ceiling (underside), Chosen point | Where each launch is aimed. |
| Tech point | Opens the crosshair | Stick moves, A sets the point, X starts. |
| Damage, Damage range | **Set**, Random; 0 to 150% by 5, **60%** | Your percent before the hit. |
| Launch speed, its range | **Set**, Random; knockback 80 to 250 by 10, **100** | The launch's strength. |
| Hit damage, its range | **Set**, Random; 1 to 30%, **12%** | The percent the hit adds. It also sets the freeze. |
| Angle, Angle range | **Auto (approximate)**, Set, Random; **0 to 355°**, steps of 5° | World launch angle: right is 0°, up is 90°. |
| Start position, Start range | **Auto (approximate)**, Set, Random; -120 to 120 units, **-40 to 40** | Your start offset from the point. |
| Time to contact, Time range | Set, **Random**; 10 to 60 frames, **20 to 40** | With Auto start, knockback limits the random draw: 20–38 frames at factory settings. |
| DI, DI direction | **Off**, Player, Set, Random; a direction, **Neutral** | Off is neutral. Player reads your stick. |
| Facing | **Toward the point**, Left, Right, Random | Which way you face at the start. |
| Delay before launch, Delay range | **Set**, Random; 10 to 90 frames, **30** | The wait at the start. Player 1 is held meanwhile. |
| Camera | **Follow**, Whole stage | Follow the attempt, or frame the whole stage. |
| Skip wizard preview | On, **Off** | On: A after Hit starts at once, without the Preview step. |

| <a id="guard-the-edge"></a><a id="juggler"></a>Start, Stop | | Reuses your set-up on the floor it was made on. Otherwise the set-up opens. |

## Good to know

<video src="https://git.syntaxbyexample.com/intpa/TrainingRoomsForUltimate/media/blob/37c5bfc34a34e2b10cdb124a7c96faaff3838dcb" autoplay muted loop playsinline controls></video>
*Stopping Eggs-ercise changes its first row back to Start.* [Open the clip](../media/rc15-practice-menu-stop.mp4)

| If | Then |
| --- | --- |
| You start a second game | The first one stops. Only one game runs at a time. |
| You close the menu with B after browsing settings | Browsing alone starts nothing; using a saved parry practice starts it on close. |
| You change a setting while a game runs | It applies at the next Start. |
| A Guard the Edge KO does not count | Check the [ground or ledge return window](../guide/guard-the-edge.md). |
| Start reopens a saved set-up | Different floor, or Guard the Edge saved an under-stage start now disallowed. |
