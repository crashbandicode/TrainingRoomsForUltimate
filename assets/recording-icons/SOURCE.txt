Recording glyphs imported by tools/layout-builder (the floppy and the loop).

Source: Google Material Symbols, from the google/material-design-icons repository on GitHub
(https://github.com/google/material-design-icons). The SVGs are the copies on review/menu-proposal
at b8cc056, docs/decisions/icons/, themselves unchanged downloads of:
  save.svg    <- symbols/web/save/materialsymbolsoutlined/save_24px.svg
  repeat.svg  <- symbols/web/repeat/materialsymbolsoutlined/repeat_24px.svg
Licence: Apache License 2.0. The full text is LICENSE-Apache-2.0.txt in this folder, copied unchanged
from that icons folder (which copied it from
https://raw.githubusercontent.com/google/material-design-icons/master/LICENSE). The repository README says:
"We have made these icons available for you to incorporate into your products under the Apache License Version 2.0."

save.png and repeat.png are those SVGs filled even-odd and rasterized at 8x, then downsampled to 64x64,
the same method as tools/render_recording_redesign.py on that branch. The RGB is white and the glyph is
the alpha, so a picture pane's vertex colour tints them. The layout builder imports them as
tr_icon_save and tr_icon_repeat.
