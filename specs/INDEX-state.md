## Cross-area notes

- The per-fighter frame and init callbacks (fighter vtable slots `main+0x4f80568` / `main+0x4f80240`, originals `main+0x614630` / `main+0x60dfa0`) are shared runtime infrastructure referenced by SPEC-state-01 and SPEC-state-06; they need their own spec in the runtime area.
- `MotionModule::change_motion` is hooked once and shared between the tech feature and the Pokémon Trainer rule (SPEC-state-05); the fighter `play_se` hook (`main+0x4cf6c0`) is shared between SPEC-state-01, 03 and 05; `EffectModule::req` / `req_follow` / `req_on_joint` are shared between SPEC-state-01 and 05. One hook per function; the specs state which rule runs first.
- `check_character_specific_status` (SPEC-state-05 §5.6) is consumed by the mash/combo area.
- The reset hub (SPEC-state-06 §5.2) calls into mash, SDI, frame counter, combo, ledge, throw and shield-tilt features owned by other areas.
